# Bilibili 插件来源

本包取自 `lekis-bilibili-plugin` 的 Lekis 适配版 `0.5.0-lekis.1`。该版本的来源说明将上游标为 GentleM4dman 的 MyGo Bilibili 插件 `0.5.0`，基线提交为 `df21c9870f0c73ee26e3553ad0ff3a79b49e369e`。[上游源码](https://github.com/GentleM4dman/mygo-music-bilibili/tree/df21c9870f0c73ee26e3553ad0ff3a79b49e369e)

Lekis 适配版向宿主传递媒体地址的过期时间，并在探测镜像时跳过返回文本或 JSON 的节点。目录维护者从适配版逐字节复制了 `plugin.json`、`index.js`、`locales/zh-CN.json` 和 `LICENSE`，另附此来源说明。
